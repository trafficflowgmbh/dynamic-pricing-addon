# TrafficFlow Dynamic Pricing Addon

Add-on for WooCommerce that enables **role-based discounts** when using the [Dynamic Pricing for WooCommerce](https://woocommerce.com/products/dynamic-pricing/) extension.

## Requirements

- [WooCommerce](https://wordpress.org/plugins/woocommerce/)
- [Dynamic Pricing for WooCommerce](https://woocommerce.com/products/dynamic-pricing/)
- [Blocksy](https://creativethemes.com/blocksy/)

## Features

- **Role-based discounts** — Apply percentage or fixed-price discounts per pricing rule set
- **Product-level configuration** — Set discounts per product in the WooCommerce product editor
- **Simple & variable products** — Full support for both product types
- **Cart & checkout** — Discounts apply correctly in cart, subtotals, and totals
- **Polylang** — Translatable strings registered for multilingual stores
- **Blocksy theme** — Integrates with Blocksy WooCommerce hooks

## Usage

1. Install and activate WooCommerce and Dynamic Pricing for WooCommerce.
2. Activate this addon.
3. Edit a product and configure Dynamic Pricing rule sets as usual.
4. In the **Pricing** section, set a discount type (None, Price Discount, or Percentage Discount) and value for each pricing group.
5. Discounts apply automatically based on the logged-in user’s role.
